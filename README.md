# سجلّ حضور عزيز — تطبيق Capacitor

هذا مشروع Capacitor جاهز يحوّل تطبيق الحضور إلى تطبيق أندرويد حقيقي (APK) قابل للتثبيت المباشر على الجوال، بدون متجر Google Play وبدون الحاجة لرابط إنترنت دائم بعد التثبيت.

⚠️ **مهم:** هذه الخطوات تحتاج **جهاز كمبيوتر** (وليس الجوال فقط) لأنها تحتاج تثبيت أدوات برمجية (Node.js و Android Studio). بعد بناء الملف النهائي (APK)، تنقله لجوالك وتثبته مباشرة.

---

## المتطلبات (تُثبَّت على الكمبيوتر مرة واحدة)

1. **Node.js** (النسخة 18 أو أحدث) — من [nodejs.org](https://nodejs.org)
2. **Android Studio** — من [developer.android.com/studio](https://developer.android.com/studio)
   (يثبّت معه تلقائيًا Android SDK اللازم للبناء)

---

## خطوات البناء

### 1) فك ضغط المشروع
فك ضغط الملف الذي أرسلته لك في أي مجلد على الكمبيوتر.

### 2) فتح Terminal / Command Prompt داخل مجلد المشروع

```bash
cd aziz-attendance-capacitor
```

### 3) تثبيت الحزم البرمجية

```bash
npm install
```

### 4) تثبيت منصة أندرويد

```bash
npx cap add android
```

هذا يُنشئ مجلد `android/` بداخله مشروع أندرويد كامل جاهز.

### 5) مزامنة ملفات الويب مع المشروع

```bash
npx cap sync
```

(أعد هذا الأمر في كل مرة تُعدّل فيها ملف `www/index.html`)

### 6) فتح المشروع في Android Studio

```bash
npx cap open android
```

سيفتح Android Studio تلقائيًا بمشروعك.

### 7) بناء ملف APK

داخل Android Studio:
- من القائمة العلوية: **Build** ← **Build Bundle(s) / APK(s)** ← **Build APK(s)**
- انتظر حتى تظهر رسالة "APK(s) generated successfully"
- اضغط **locate** لإيجاد الملف — سيكون بمسار مشابه لـ:
  ```
  android/app/build/outputs/apk/debug/app-debug.apk
  ```

### 8) نقل الملف للجوال وتثبيته

- انسخ ملف `app-debug.apk` لجوالك (عبر كابل USB، بلوتوث، أو رفعه لجوجل درايف وتحميله).
- افتحه من جوالك — قد يطلب منك تفعيل **"تثبيت من مصادر غير معروفة"** (Install unknown apps) من الإعدادات، وافق عليها.
- سيثبَّت التطبيق بأيقونة حقيقية في قائمة التطبيقات، تمامًا مثل أي تطبيق آخر.

## ملاحظات مهمة

- **البيانات:** التطبيق يستخدم `localStorage` داخل الـ WebView الخاص به، وهذا يعني بياناتك محفوظة **داخل التطبيق نفسه** بشكل معزول وآمن — أكثر ثباتًا من نسخة المتصفح، ولن تُمسح عند مسح بيانات متصفح آخر.
- **تعديل التطبيق لاحقًا:** إذا أردت مني تعديل أي شيء بالتصميم أو الوظائف، عدّل ملف `www/index.html` بالتعديل الجديد الذي أعطيك إياه، ثم أعد الخطوات 5 و7 فقط (لا حاجة لإعادة كل الخطوات).
- **الأيقونة والاسم:** حاليًا الاسم "سجلّ حضور عزيز" ومعرّف التطبيق `com.aziz.attendance`، معرّفان في ملف `capacitor.config.json`. لتغيير أيقونة التطبيق، ضع صورة مربعة بحجم 1024×1024 باسم `icon.png` واستخدم أداة [Capacitor Assets](https://capacitorjs.com/docs/guides/splash-screens-and-icons) لتوليد كل الأحجام تلقائيًا.

## بديل أسهل بدون Android Studio

إذا لم ترغب بتثبيت Android Studio، هناك خدمات أونلاين تبني APK من مشروع Capacitor مباشرة (مثل **Appflow** من Ionic، أو **PWA Builder** — لكنها ليست دائمًا مجانية بالكامل أو قد تحتاج حساب). الطريقة الموثّقة أعلاه هي الطريقة الرسمية والمجانية بالكامل.
