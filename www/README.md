# سجلّ حضور عزيز — دليل الإعداد الكامل على GitHub

هذا الدليل يشرح بالتفصيل كيف تنشئ التطبيق من الصفر على GitHub، بحيث كل تحديث مستقبلي **يحدّث النسخة المثبّتة على جوالك مباشرة بدون حذفها وبدون فقدان بياناتك المحفوظة**.

---

## الملفات المطلوبة وأماكنها بالضبط

```
اسم-المستودع/
├── package.json                              ← بجذر المستودع
├── capacitor.config.json                     ← بجذر المستودع
├── www/
│   └── index.html                            ← بداخل مجلد www فقط
└── .github/
    └── workflows/
        └── build-apk-signed.yml              ← بهذا المسار بالضبط
```

⚠️ **الأهم:** لا تضع `package.json` أو `capacitor.config.json` داخل مجلد `www/` — يجب أن يبقيا في الجذر الرئيسي للمستودع، وفقط `index.html` يذهب داخل `www/`.

---

## الخطوات — من الجوال عبر متصفح GitHub

### 1) أنشئ مستودعًا جديدًا (أو استخدم مستودعك الحالي)
اذهب إلى `github.com` ← **+** ← **New repository** ← أعطه اسمًا ← Public ← **Create repository**

### 2) أنشئ www/index.html
1. **Add file** ← **Create new file**
2. اسم الملف: اكتب `www/index.html` بالضبط (الشرطة تُنشئ المجلد تلقائيًا)
3. الصق محتوى ملف `index.html` المرفق (افتحه، انسخ كل شيء، ألصقه)
4. **Commit new file**

### 3) أنشئ package.json
1. **Add file** ← **Create new file**
2. اسم الملف: `package.json`
3. الصق محتواه
4. **Commit new file**

### 4) أنشئ capacitor.config.json
نفس الخطوات باسم `capacitor.config.json`

### 5) أنشئ ملف الأتمتة (بناء APK موقّع)
1. **Add file** ← **Create new file**
2. اسم الملف: `.github/workflows/build-apk-signed.yml` بالضبط
3. الصق محتوى `build-apk-signed.yml`
4. **Commit new file**

---

## إضافة مفتاح التوقيع (خطوة تُنجَز مرة واحدة فقط)

هذا المفتاح يضمن أن كل نسخة تبنيها مستقبلاً "متوافقة" مع النسخة المثبّتة على جوالك، فتقدر تحدّثها مباشرة بدون حذف.

### أضف 3 أسرار (Secrets) في المستودع:

1. من صفحة المستودع: **Settings** ← (من القائمة الجانبية) **Secrets and variables** ← **Actions**
2. اضغط **New repository secret** وأضف كل واحد من هذه على حدة:

| الاسم (Name) | القيمة (Value) |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | الصق النص الطويل الموجود في الرسالة أدناه |
| `ANDROID_KEYSTORE_PASSWORD` | `azizAttendance2026` |

⚠️ احتفظ بنسخة من قيمة `ANDROID_KEYSTORE_BASE64` في مكان آمن (ملاحظات جوالك مثلاً) — إذا فقدتها مستقبلاً، لن تقدر تحدّث التطبيق أبدًا وستحتاج تبدأ بمفتاح جديد (وتحذف النسخة القديمة من الجوال).

---

## تشغيل البناء وتثبيت التطبيق

1. بعد إضافة كل الملفات والأسرار، اذهب لتبويب **Actions** أعلى المستودع
2. سيبدأ البناء تلقائيًا (أو اضغط **Run workflow** لتشغيله يدويًا)
3. انتظر 3-5 دقائق حتى يكتمل (✅ خضراء)
4. اضغط على البناء المكتمل ← انزل لقسم **Artifacts** ← حمّل **aziz-attendance-apk**
5. فك ضغط الملف الذي حمّلته، وافتح `app-release-signed.apk` من جوالك لتثبيته

---

## عند كل تحديث مستقبلي

1. عدّل فقط محتوى `www/index.html` بالنسخة الجديدة (نفس طريقة النسخ واللصق و Commit)
2. اذهب لـ **Actions** وانتظر اكتمال البناء الجديد
3. حمّل الـ APK الجديد وافتحه من جوالك مباشرة
4. سيسألك الجهاز "Update" وليس "Uninstall" — اضغط **Update**، وبياناتك المحفوظة تبقى كما هي تمامًا

---

## ملاحظات

- لا تغيّر `appId` في `capacitor.config.json` مستقبلاً (`com.aziz.attendance`) — تغييره يجعل أندرويد يعتبره تطبيقًا مختلفًا تمامًا.
- لا تغيّر اسم الحقل `alias` للمفتاح (`aziz-attendance`) في ملف الأتمتة.
- طالما نفس الأسرار الثلاثة موجودة في المستودع، كل بناء مستقبلي سيبقى متوافقًا مع التثبيت الحالي على جوالك.
